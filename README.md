# ლექციების ცხრილის RAG ჩატბოტი

ჩატბოტი პასუხობს ქართულ კითხვებს უნივერსიტეტის ლექციების ცხრილსა და ჯგუფების სიაზე (ორი PDF). პასუხი მხოლოდ მოძიებულ ჩანაწერებზეა დაფუძნებული; თუ ინფორმაცია არ არის, ბოტი ამას ამბობს და არ იგონებს.

> _აქ ჩასვი სკრინშოტი ან GIF._

## როგორ მუშაობს

```
PDF-ები -> parse_pdf.py -> lessons.json (150 ლექცია, სპეციალობის სახელებით)
        -> ingest.py: multilingual-e5-base embedding -> ChromaDB
კითხვა  -> retriever.py: ზუსტი ფილტრი (ჯგუფი/დღე/აუდიტორია/დრო) ან ვექტორული ძებნა
        -> rag_chain.py: Groq LLM -> ქართული პასუხი
        -> streamlit_app.py: ჩატი + წყაროები
```

## მთავარი გადაწყვეტილებები

- **ერთი ლექცია = ერთი chunk** მეტადატით (`day, start, end, subject, group, room, type`).
- **ორი PDF გაერთიანებულია**: ლექციას ჯგუფის სპეციალობაც ახლავს.
- **ჰიბრიდული ძებნა**: ჯგუფი, დღე, აუდიტორია და დრო კოდით იფილტრება, ხოლო ვექტორული ძებნა მხოლოდ ღია კითხვებზეა.
- **ქართული ენა**: PDF-ის ტექსტი სწორად იკითხება (OCR არ დასჭირდა), მრავალენოვანი მოდელი, დღეების ძებნა ფუძით.

## შეფასება

30 ავტომატურად დაგენერირებული კითხვა, 7 კატეგორია, მათ შორის 4 უპასუხო.

| მოდელი | სიზუსტე |
|---|---|
| gpt-oss-120b | 29/30 (96.7%), სხვა გაშვებებზე 28–30 |
| gpt-oss-20b | 25/30 (83.3%) |

ტესტმა აჩვენა ბაგი, სადაც ჯგუფის ნომერი აუდიტორიად იკითხებოდა. გასწორების შემდეგ "ჯგუფი + დღე" კითხვები 6/8-იდან 8/8-ზე გადავიდა.

## შეზღუდვები

- ტესტი იმავე მონაცემიდანაა დაგენერირებული და ერთგვაროვანია, ამიტომ ის regression ტესტია და არა დამოუკიდებელი benchmark.
- შედეგები გაშვებებს შორის ოდნავ იცვლება.
- არ არის მხარდაჭერილი შეჯამებითი კითხვები ("რომელ დღეს მეტი ლექციაა?") და გაგრძელების კითხვები ("და სამშაბათს?").
- უცნობი ჯგუფის ნომერზე ბოტი LLM-ის პასუხზეა დამოკიდებული და არა ცალკე შემოწმებაზე.

## სტეკი

Python 3.12 · pdfplumber · sentence-transformers · ChromaDB · Groq API · Streamlit

## გაშვება

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

`.env`-ში ჩაწერე `GROQ_API_KEY=...`, PDF-ები ჩააგდე `data/raw/`-ში, შემდეგ:

```
python src/parse_pdf.py
python src/ingest.py
streamlit run app/streamlit_app.py
python tests/build_eval.py
python tests/run_eval.py
```
